### Проверено фактическими UI-нажатиями

- Предупреждение показывается один раз на установку; последующее создание Activity не возвращает его.
- Постоянный 12-значный ID не меняется при повторном создании хранилища/сбросе пробных финансовых данных и виден в профиле.
- Создание PIN требует совпавшего подтверждения. Неверный код не открывает вход; смена/отключение требуют действующего кода. Есть сохраняемая задержка после ошибок, блокировка в фоне и закрытый запуск после создания Activity.
- У включённого PIN нет кнопки обхода «войти без кода». PIN-верификатор не находится в снимке/экспорте данных.
- Перевод, покупка товара, инвестиционная покупка и открытие/финансирование вклада выполняются один раз при повторном нажатии, проходят занятое состояние и результат, без отдельной проверки перевода.
- Полная большая отрицательная сумма помещается в одну видимую строку; даты не выводятся ISO-строкой. Вклад не предлагает оплату картой, кэшбэк или блокировку карты.
- Валютный обмен начисляет правильные целые минимальные единицы и показывает валюту получателя.
- Настройка English меняет настоящие интерфейсные подписи, а не только индикатор выбора.
- Кнопки имеют нативные состояния нажатия/возврата; launcher — AdaptiveIconDrawable.
- Подписка Pro списывает местную сумму один раз и сохраняет статус; отклик сохраняется/отменяется; карта выпускается один раз без появления новых денег.
- Поиск, избранное/предложения/адрес/настройки, прежняя миграция, шрифты, переключатель, панели карты/сканера и движения входа/выхода проверены.

### JVM: защита и точность

Соль/PBKDF2, неверный PIN и допустимая длина, отсутствие изменения исходного объекта, точное восстановление JSON с пустыми массивами/объектами/null, очистка вложенных секретов, checksum/schema, большие целые суммы, фильтрация внутренних переводов, валютные проводки/округление/дубликаты, атомарный вклад и отсутствие полусозданного счёта, блокировка повторного финансирования непополняемого вклада.

Firebase-протокол проверен внедряемым транспортом без живой сети: Android package headers, обновление токена/кодировка, закрытый nonce/snapshot, отказ при публичной базе, очистка nonce, ETag/If-Match и конфликт версии. Это не подмена настоящей Firebase-проверки.

## Реальная проверка предоставленного Firebase-конфига

**HTTP 400 — `CONFIGURATION_NOT_FOUND`** при анонимном входе.

- Технический Firebase-пользователь не создавался.
- Профиль/счета/история и данные скриншотов не отправлялись.
- Реальное сквозное сохранение RTDB **не подтверждено**: серверная авторизация ещё требует настройки владельцем проекта.
- Нужно включить **Authentication → Anonymous** и применить **firebase/database.rules.json**. Подробно: `firebase/SETUP.md`.

После настройки приложение сохраняет в `users/<auth.uid>/snapshot`. PIN хранится только локально; Firebase refresh token — Android Keystore/AES-GCM. До загрузки профиля клиент проверяет, что база не открыта без авторизации. Используется обычный TLS без обхода ошибок сертификата.

Номер профиля не является паролем/доступом к чужому облачному узлу. Анонимный профиль привязан к этой установке; экспорт/импорт нужен для переноса. Выбранное фото входит в облачную копию при включённом сохранении; кадры камеры не сохраняются/не отправляются.

## Источники и приватность

Третья запись около 930,936 с изучена по 186 обзорным и 424 плотным образцам переходов. Долгие загрузки и внешняя ошибка TLS не воспроизводились. Оформление выпущенной 1.1 осталось базой, новые меню — нативные.

Частные оригиналы, временные кадры/листы анализа, браузерное хранилище и 11 новых исходных скриншотов удалены локально. Первые две удалённые записи повторно не загружались. В APK/исходниках нет реальных имён, телефонов, сумм, реквизитов или номеров лояльности из записей. Начальные данные вымышлены; телефоны `(000)`. Декор/публичные узоры без EXIF/XMP; новая фотография подушек — небрандовый AI-декор, не фотография пользователя.

Закрытого ключа подписи/служебных токенов в исходном архиве нет. Клиентский google-services.json включён по запросу для сборки этого проекта; это не административный ключ. Локальное удаление не удаляет удалённое вложение/файл у владельца ссылки.

## Что проверить на телефоне

1. Установка нового пакета, различение старого приложения/помощника, системный экспорт/импорт JSON и сохранение аватара.
2. PIN при холодном старте/возврате, клавиатура, Android Keystore на конкретном устройстве, тайм-аут в фоне.
3. Работа Firebase после серверной настройки, переход офлайн/онлайн, повторный вход и сохранение/восстановление.
4. Реальная плавность/FPS и системные жесты при частотах/масштабах анимации устройства; все снимки — только headless API 28.
5. Камера, подсветка, распознавание QR/галерея, повороты/сенсоры, вибрация, OEM-панели/шрифты.
6. Создание/открытие PDF на Android, отметка недействительности на каждой странице, системное «Поделиться».

Нет настоящего банка/биржи/NFC-платежей/доставки/вакансий работодателя/автоматических банковских списаний. Эти функции — местная модель с вымышленными данными и фиксированными курсами/котировками.
