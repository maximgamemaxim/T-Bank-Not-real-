# Перенос из 2.2 в com.mvt.tbank

По вашему запросу основной пакет изменён с `ai.arena.bankdemo` на **`com.mvt.tbank`**. Android изолирует данные разных пакетов, даже если их подписали одним сертификатом. Новая 2.3 не может сама прочитать закрытые SharedPreferences старой 2.2.

## Если нужны прежние счета и история

1. **Не удаляйте старую 2.2.**
2. Установите **TBank-2.2-export.apk** поверх неё. Это необязательный помощник с тем же старым пакетом, прежней подписью, versionCode 6 / версией 2.2.1. Название в списке приложений — **«Т-Банк · перенос»**.
3. Откройте в помощнике **Профиль → шестерёнка → Настройки**. Кнопка экспорта находится вверху. Она также добавлена на экран «Доступы к данным».
4. Нажмите **«Экспорт для переноса в новое приложение»** и сохраните `tbank-legacy-profile.json` в выбранную вами папку.
5. Установите основной **TBank-2.3.apk**. В сведениях о приложении должен быть пакет **com.mvt.tbank**.
6. В новой версии: **Витрина → Все сервисы → Сохранение данных → Импортировать копию**.
7. Выберите JSON и подтвердите замену текущего начального набора данных. Импортируются профиль, счета, история, настройки и выбранное в старом приложении фото.
8. Убедитесь, что всё перенеслось. Только после этого при желании удалите старое приложение и больше не нужную копию JSON.

Помощник не меняет остатки/историю, не сбрасывает состояние, не подключается к Firebase и не имеет INTERNET. Он только добавляет явный экспорт файла. Новая версия не включает PIN и Firebase-ключи в такие файлы. Старая 2.2 настоящего сохранённого кода входа не имела; код 2.3 задаётся заново.

Храните JSON как личную резервную копию: в нём находятся данные выбранного профиля. Не отправляйте его посторонним. Присланные для разработки скриншоты или исходные записи в резервную копию не добавляются.

## Если прежние пробные данные не нужны

Можно сразу установить 2.3 как отдельное приложение. Старое при этом не удаляется. В новом создаются начальный вымышленный набор и постоянный 12-значный номер профиля.

## Для сборки помощника из исходников

Нужен ранее выданный **TBank-Native-2.2-source.zip**, SDK 35, JDK 11+ и тот же ключ подписи:

```bash
python3 qa/build_legacy_export.py /path/to/TBank-Native-2.2-source.zip /path/to/TBank-2.2-export.apk
```

Закрытый ключ в исходных архивах не распространяется. Подпись помощника проверена; установка и работа системного файлового диалога на вашем физическом устройстве отдельно не выполнялись.
